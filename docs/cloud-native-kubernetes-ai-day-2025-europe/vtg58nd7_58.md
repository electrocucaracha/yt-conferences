# Summary

The speaker from INFN presents Interlink, a tool designed to bridge Kubernetes clusters with remote resources such as EuroHPC supercomputers, GPU-heavy VMs, and other Kubernetes clusters.
By leveraging Virtual Kubelet and a simple REST API plugin architecture, Interlink translates standard Kubernetes pod requests into custom job submissions, allowing users to access high-performance hardware seamlessly while maintaining a unified cluster view.
The presentation highlights new features that overcome previous limitations, specifically the implementation of an overlay network to share in-cluster networking and support for a greater number of volumes.
A live demonstration shows a Ray cluster for distributed training being deployed across virtual nodes on a supercomputer, proving that the system functions transparently like a native Kubernetes environment.
The project, which has joined the Cloud Native Sandbox, supports both single-tenant and multi-tenant scenarios and is compatible with workflow engines like Argo, inviting contributions due to its simple codebase.
