# Summary

The speaker, a maintainer of MetalKube, outlines the project’s journey from a working system to CNCF incubation, emphasizing that trust and governance are critical bottlenecks for enterprise adoption rather than code quality alone.
To address this, the team transitioned from informal, implicit processes to structured, verifiable artifacts by centralizing governance documentation in a dedicated community repository and defining clear contributor roles and security responsibilities.
Key structural changes included establishing a dedicated security team with a formal disclosure process, automating release cadences, and making community activities and decision-making transparent through public meetings and recorded sessions.
The speaker highlights that CNCF incubation requires proving sustainability, neutrality, and security across five interconnected areas: governance, engineering, security, community, and ecosystem, rather than just technical functionality.
Finally, the talk provides a practical checklist for other projects, advising them to treat governance and security as first-class components, maintain clear adoption evidence, and structure their documentation to align with CNCF’s evolving review tracks to ensure long-term project health and trust.
