# Summary

James C., Principal Engineer for BT Group’s network cloud platform, highlights the company’s role in supporting critical national infrastructure and major UK events such as the Oasis reunion at Wembley Stadium and the GP on the south coast.
He notes that these events generated massive data loads, with Wembley producing 33.5 terabytes and Cheltenham’s data demand nearly doubling to 38.2 terabytes, underscoring the need for robust network capabilities.
BT’s infrastructure is built on an on-premises OpenStack cloud platform using Canonical’s charmed OpenStack, which provides the flexibility to integrate compliance monitoring, logging, and custom provisioning tools required for critical services.
To meet evolving demands driven by 5G and the UK Telecom Security Act, the team has modernized their stack by upgrading OpenStack versions, replacing the SDN layer with OVN, and introducing Kubernetes capabilities via Rancher R2 to support edge computing.
James emphasizes that maintaining a scalable, future-proof system relies heavily on strong partnerships with open-source vendors like Canonical and SUSE, shifting from a consumption mindset to a collaborative approach that ensures continuous innovation and service reliability.
