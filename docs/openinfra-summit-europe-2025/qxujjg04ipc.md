# Summary

Su, a representative of the AN Group’s container infrastructure team and open source lead, introduced the Kata Containers project, which he co-announced in 2017.
He highlighted two major recent initiatives: sandboxing large language models using Kata Containers with GPU pass-through and confidential computing support, and creating secure sandboxes for AI agents to protect infrastructure from potentially unsafe code.
To enhance usability, the team improved sandbox launch speeds through image acceleration and developed PVM virtualization, allowing Kata Containers to run on standard EC2 instances rather than requiring expensive bare-metal hardware.
Additionally, Su presented community sessions and data-driven insights on AI development trends derived from analyzing developer behaviors on GitHub, emphasizing the value of neutral open-source data for strategic decision-making.
