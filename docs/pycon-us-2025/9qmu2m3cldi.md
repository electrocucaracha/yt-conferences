# Summary

Russell Keith McGee, a member of the CPython Core team and founder of the Beware project, introduces an upcoming Python US tutorial designed for individuals who know how to write Python but lack experience in delivering their code to others or converting it into mobile applications.
The course teaches participants how to build an app with a native graphical user interface that runs on multiple desktop and mobile operating systems without modification, using only Python.
Attendees need only basic Python skills to learn how to create an app capable of taking photos or obtaining GPS readings and subsequently publish it to an app store.
Tickets for this tutorial are currently available, and McGee hopes to see interested learners at the event.
