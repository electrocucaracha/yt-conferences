# Summary

Carlos Araníbar presents a talk on designing and building custom keyboards using Python, tracing the evolution from the 1860s typewriter to modern compact layouts like TKL, 65%, and 40% sizes.
He explains that while the QWERTY layout persists due to historical inertia rather than optimal efficiency, alternatives like the Dvorak layout offer better ergonomics by placing frequently used keys in the home row.
The presentation details the hardware components required for custom builds, including PCBs, microcontrollers like Arduino, and switches, emphasizing that configurations are stored on the device itself for cross-platform compatibility.
Araníbar demonstrates how to use open-source tools and Python scripts to design PCBs and practice typing, while also discussing ergonomic solutions such as split keyboards and ortholinear layouts to reduce wrist strain.
He concludes by advocating for personalized keyboard setups that improve typing efficiency and comfort, noting that even without a full custom build, users can benefit from ergonomic commercial keyboards and layout optimizations.
