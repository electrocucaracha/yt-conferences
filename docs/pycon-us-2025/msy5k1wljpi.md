# Summary

William Woodruff of Trail of Bits presents PEP 740, a new generation of cryptographic attestations for PyPI designed to enhance supply chain security by binding package identities to their sources.
Unlike traditional PGP signing, which suffered from low adoption due to complex key management and distribution issues, PEP 740 leverages Sigstore and Trusted Publishing to provide short-lived, identity-based signatures that are generated by default in CI/CD workflows.
This approach eliminates the need for users to manage long-lived private keys and ensures that the index verifies the authenticity of uploads, thereby reducing risks associated with project takeovers and index compromises.
The implementation has already achieved significant adoption, with 14% of new packages and over 20% of top-downloaded packages utilizing attestations, while also improving incident response capabilities through transparency logs.
Looking ahead, the ecosystem aims to integrate these attestations into lockfiles via PEP 751 to enable default end user verification, ensuring that tools like pip and uv can automatically validate package provenance and detect malicious changes during installation or updates.
