# Summary

Elaine Wong, the conference chair, welcomes attendees to the third day of PyCon US in Long Beach, highlighting the event’s first dedicated AI and security tracks, a Spanish-language keynote with English translations, and the 15th anniversary of PyLadies.
She provides essential logistics, including Wi-Fi credentials, venue navigation tips, and volunteer opportunities, while emphasizing the importance of the code of conduct and community inclusivity.
Sponsors from Nvidia, Bloomberg, and Meta present their contributions to the Python ecosystem, such as the release of CUDA Python 1.0, the open-source memory profiler "memory," and the stable release of the Pyre Fly type checker.
Finally, E.
Dan Nicholson, the Executive Director of the Python Software Foundation, shares a personal story about the welcoming nature of the Brazilian Python community and encourages attendees to both support newcomers and engage in collaborative learning opportunities like sprints.
