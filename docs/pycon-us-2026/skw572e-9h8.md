# Summary

Craig Dennis and Hood Chatham presented Cloudflare’s developer platform, highlighting its global network of over 330 data centers that delivers content within 50 milliseconds to 95% of the connected world.
Dennis demonstrated the platform’s capabilities through live demos, including a Python-based "MS Paintification" app that utilizes R2 object storage, AI Gateway for unified billing, and durable workflows with automatic retries.
He also showcased Durable Objects by hosting a real-time multiplayer balloon-shooting game for the audience, illustrating how these stateful, hibernatable servers can handle WebSocket connections and SQLite databases efficiently.
Hood Chatham then explained the technical architecture, revealing that Python Workers are powered by Pyodide, which compiles CPython to WebAssembly to run within the V8 engine of the Cloudflare Workers runtime.
The session concluded with a discussion on the platform’s roadmap, including improved Pythonic APIs, support for more native packages via PEP 783, and comparisons to AWS Lambda, emphasizing the simplicity of deployment and the cost-effectiveness of paying only for active compute time.
