# Summary

This panel discussion, hosted by Donis, features prominent figures from the core CPython and scientific Python communities, including Mike Dropboom, Carol Willing, Jonathan Byar, Savannah Stroski, and Travis Oliphant.
The group explores strategies to bridge the gap between these two ecosystems, emphasizing the need for active listening, empathy, and clear communication to foster mutual understanding and collaboration.
Key topics include the importance of interoperability standards like the NumPy Array API, the value of incubator models such as "Faster CPython" and "Wheel Next" for accelerating development, and the critical role of non-code contributions like evangelism and facilitation.
The panelists also address significant community challenges, notably criticizing the current discourse platform for causing burnout and proposing alternatives to improve the PEP review process.
The session concludes with a strong call to action for the audience to engage proactively, find mentors, and contribute to the open-source ecosystem, while an audience member highlights the urgent need for improved packaging and installation experiences for scientific tools.
