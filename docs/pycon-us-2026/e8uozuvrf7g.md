# Summary

Pablo, a Python Core Developer and Steering Council member, delivered the first Spanish-language keynote at PyCon US, using the metaphor of the Sagrada Familia to discuss the current state of open source.
He argued that the integration of AI has fundamentally disrupted the traditional collaborative model, where code reviews served as a vital mechanism for mentorship and community building.
By citing data on the surge in AI-generated pull requests and security vulnerabilities, he highlighted how maintainers are overwhelmed by low-effort, high-volume contributions that often lack human understanding, leading to burnout and a breakdown in trust.
The talk emphasized that while AI facilitates rapid code generation, it simultaneously enables sophisticated supply chain attacks and erodes the "back pressure" that previously ensured quality and effort in contributions.
Despite these challenges, Pablo concluded with a message of hope, asserting that the human connections and shared purpose within the Python community remain the true foundation of the project, urging attendees to view their collective efforts as building a lasting legacy together.
