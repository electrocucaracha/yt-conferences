# Summary

Juanita, a PhD candidate at UC Santa Cruz, and Seth Larson, the security developer and resident at the Python Software Foundation, are chairing the "Trailblazing Python Security" track.
This track focuses broadly on security within the Python ecosystem, covering topics such as PIP usage, vulnerability management, supply chain security, and the development of security tools.
The chairs emphasize the importance of sharing experiences from both users and developers, noting that security developers often learn significantly from those who build applications with Python.
They encourage potential speakers to submit proposals even if they are not professional security experts, as the track values personal experiences and practical insights over formal credentials.
Additionally, they advise first-time conference speakers to request a mentor during the submission process and to clearly define what they want their audience to learn from their talk.
