# Summary

The speakers, Martin Safenko and Yan, discuss their experience writing "Quarkus in Action," a book about the popular Java framework Quarkus.
They share their motivations for writing the book, which includes showcasing the developer experience, performance, and productivity features of Quarkus.
The book covers various topics, including getting started with Quarkus, development experience, testing, security, databases, reactive programming, messaging, and deployment in the cloud.
The authors discuss the challenges of writing a comprehensive book on a rapidly evolving framework, such as Quarkus, which has over 850 extensions.
They provide advice on when to use JVM versus native compilation, highlighting that native is suitable for serverless deployments with fast startup times, while JVM is better suited for longer-running applications.
