# Summary

The speaker, Jamie Dicken, discusses how applying chaos engineering principles can tangibly improve security posture at organizations.
He highlights that many security programs are based on assumptions and theories rather than evidence, leading to missed opportunities for protection and bad strategic decisions.
Chaos engineering can help address this by performing experiments to collect data about security controls' performance, allowing for a more evidence-based understanding of security posture.
Dicken shares his experience implementing continuous verification and validation at Cardinal Health, a healthcare company, which has improved their security posture by making it based on evidence rather than outdated beliefs or assumptions.
