# Summary

The speaker is a developer and program manager at Microsoft, discussing their experience with the Edge browser's developer tools.
They explain that instead of taking screenshots, they use the live browser to demonstrate features like Focus Mode, which allows users to interact with only one tool at a time.
The speaker highlights the Command Menu as a powerful feature for developers, enabling them to type commands and access various tools without navigating through menus.
They also discuss the Console, Elements, Sources, and Network panels, showcasing their capabilities and usefulness in debugging and inspecting web pages.
Additionally, they introduce features like Snippets, which allow users to create reusable code blocks, and the Changes tool, which displays a diff of changes made to files.
The speaker concludes by emphasizing that developer tools are not just for developers but can be useful for anyone who wants to interact with the web, and invites viewers to explore and learn more about these features.
