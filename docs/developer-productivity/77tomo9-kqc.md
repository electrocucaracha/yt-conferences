# Summary

Francisca Hinkleman, a senior engineer at Google, and Anu, another senior engineer, presented a talk on using Node.js with Google Sheets.
They aimed to show how anyone can work with sheets, not just developers.
The duo created an application that automates gathering metrics from GitHub and sends the data to a spreadsheet, generating charts in the process.
This allows for quick iteration and prototyping with data.
The team used serverless functions on Google Cloud Platform (GCP) to deploy their code, eliminating manual setup and configuration.
They also implemented authorization using OAuth 2.0, ensuring secure access to user data.
The application generates reports automatically, saving time and effort for users.
