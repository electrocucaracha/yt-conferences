# Summary

Denis, a developer advocate at Couchbase, discusses the hidden costs of poor database access.
He emphasizes that as software developers, it's acceptable to prioritize productivity over performance, but warns against trading off performance for nothing.
Denis highlights common issues with databases, including joins, prepared statements, and ORM frameworks like Hibernate.
He also explains how relational databases are designed to work on a single machine, making scaling challenging.
To address these limitations, Denis introduces SQL Plus Plus, a new query language that allows querying hierarchical data in a more efficient way.
This approach enables developers to write less verbose code and get rid of the overhead of ORMs, ultimately leading to improved performance and productivity.
