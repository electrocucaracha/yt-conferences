# Summary

Hill Marman, a computer scientist and project manager at Vertica, explains their flat organizational structure with 130 employees.
They believe decisions should be made close to where competence is relevant, using "Meaningful Affected" - a process where colleagues discuss and decide on important issues together.
This approach eliminates the need for traditional management, instead relying on algorithms and peer-to-peer assessments for tasks like salary and hiring.
