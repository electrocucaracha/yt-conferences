# Summary

As a software engineering manager at Spotify, Lee explains the purpose of Backstage, their open developer platform.
With increasing complexity in tooling and knowledge bases for engineers, Backstage aims to be a single pane of glass, surfacing relevant information at the right time without taking away existing tooling or complexity.
It's an extensible platform with experts owning plugins and tools, offering features like creation, management, and exploration, including software catalogs, documentation, and tech talks, to reduce cognitive load and provide a consistent design for engineers.
