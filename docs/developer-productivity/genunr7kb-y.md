# Summary

The speaker discusses continuous verification, a proactive experimentation tooling discipline for verifying system behavior.
It builds upon continuous integration (CI) and continuous delivery (CD), aiming to ensure systems deliver business properties while generating features quickly.
The speaker highlights myths about availability, such as removing people who cause accidents or simplifying systems, which are not effective in improving reliability.
Instead, they emphasize the importance of adapting to risk, intuition, and reversibility in software engineering, where tools like XP and agile methodologies enable design decisions that improve system reliability.
