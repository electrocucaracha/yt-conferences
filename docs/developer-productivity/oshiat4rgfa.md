# Summary

Tudor Girba discusses moldable development, a concept that aims to make software systems more understandable and controllable by humans.
He explains how the traditional approach of reading code is not efficient due to its high complexity and the need for manual analysis.
Instead, he proposes using visualizations and tools to facilitate understanding and exploration of software systems.
The Glamorous Toolkit is an example of this approach, allowing users to create custom views and interact with their code in a more intuitive way.
Tudor believes that augmenting human cognition through tools will be essential for making software "habitable" and increasing productivity.
