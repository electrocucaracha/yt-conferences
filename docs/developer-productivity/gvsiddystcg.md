# Summary

Christian Clausen and Adam Tornhill discuss the social side of refactoring and code quality in software development.
They emphasize that organization, team familiarity with the code, and human factors are crucial aspects of code complexity beyond just the code itself.
The conversation highlights the importance of celebrating small wins, identifying successful refactorings, and using tools like CodeScene to manage technical depth.
Clausen shares his experience with functional programming languages like Clojure, which he finds attractive due to its ability to allow each person to do more than what they could have done individually.
