# Summary

Dave Farley, a software developer and author, discusses his book "Modern Software Engineering" with Saleem Siddiqui, who wrote "Learning Test-Driven Development".
They talk about the importance of test-driven development (TDD) in software engineering, its benefits, and how it can be applied to different programming languages.
Dave emphasizes that TDD is not just about writing unit tests but also about designing better code through the process of testing and refactoring.
He highlights the need for continuous integration and deployment, as well as the importance of involving engineers and managers in adopting TDD practices.
The conversation also touches on the challenges of applying TDD to new technologies like serverless architecture and the need for a culture shift within the industry to prioritize TDD.
