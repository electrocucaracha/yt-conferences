# Summary

Adonai, a Colombian AI expert and Google Developer Expert, presented a talk titled "Hacking Thoughts" at a tech conference, focusing on the integration of brain-computer interfaces with large language models to create personalized wellness solutions.
He introduced the Neurosity Crown device, which reads electrical brain signals to categorize mental states such as concentration, meditation, and sleep, explaining how these frequencies can be monitored to enhance productivity and well-being.
The core of his demonstration was a real-time system that uses a Random Forest model to analyze live brainwave data and feeds this information into a ChatGPT-based agent named "Ale," which provides dynamic, context-aware meditation guidance.
To make the experience more engaging, Adonai utilized ElevenLabs to clone the voice of his partner, allowing the AI to speak with her unique tone and cadence, thereby creating a highly personalized feedback loop that adjusts its suggestions based on the user's real-time focus levels.
The presentation concluded with a code walkthrough of the data collection pipeline, model training process, and API integration, emphasizing the potential for personalized AI agents to improve mental health and cognitive performance through accessible technology.
