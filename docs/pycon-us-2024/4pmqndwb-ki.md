# Summary

Sebastian Flores presents a talk on using Python and data storytelling to avoid "Death by PowerPoint," arguing that effective communication relies on narrative structure rather than just software tools.
He outlines key storytelling principles, such as never revealing the ending early, focusing on peak emotions and strong conclusions, and adhering to the "show, don't tell" rule to engage audiences through action and visualization rather than static text.
Flores emphasizes that while exploratory tools like Tableau are useful for data discovery, they lack the narrative direction needed for impactful presentations; instead, he advocates mastering specific Python libraries like Matplotlib, Seaborn, or Plotly to craft custom visualizations that highlight only relevant details.
To facilitate this, he recommends "show, don't tell" presentation tools such as Quarto, Jupyter with RISE, and Streamlit, which allow for live code execution and dynamic content, making them superior to traditional slide decks for technical audiences.
Finally, he advises speakers to treat AI as a source of inspiration for rapid drafting, to select the right tool based on the need for interactivity, and to invest time in refining their presentations to ensure they resonate emotionally and drive action.
