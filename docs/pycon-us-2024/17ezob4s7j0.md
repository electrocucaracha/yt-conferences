# Summary

Sydney Runel, the lead maintainer of Pydantic, presents performance optimization tips for building lightning-fast Python applications using the library’s V2 release.
She begins by recommending specific coding practices, such as using the `model_validate_json` function to avoid unnecessary Python object materialization, initializing type adapters only once to prevent redundant schema building, and utilizing specific type hints like `list` and `dict` instead of generic `Sequence` or `Mapping` types to skip extra validation checks.
The core of the presentation focuses on tagged unions, also known as discriminated unions, which significantly improve performance by validating data against only the relevant union member based on a discriminator field, rather than testing all possible types.
This approach not only accelerates validation, particularly in nested or recursive models, but also provides clearer error messages and better JSON schema support for documentation.
Runel concludes by outlining future performance enhancements, including the use of SIMD and JIT compilation in Rust, lazy evaluation of attributes, and faster schema building, while also announcing Pydantic Logfire, a new commercial observability tool designed specifically for Python developers.
