# Summary

Leah Waser, founder of the nonprofit Pi OpenAI, presents a talk titled "Friends Don't Let Friends Package Alone," emphasizing the critical need to reduce cognitive overload for beginners navigating the complex Python packaging ecosystem.
Drawing from her experience maintaining the open-source package `straw`, she highlights how an abundance of tools and fragmented documentation often leads to decision paralysis, particularly for scientists who are not packaging experts.
To address this, Pi OpenAI developed a community-reviewed, beginner-friendly packaging guide that prioritizes fundamental concepts over specific tool opinions, ensuring that users can achieve early wins by successfully creating their first pure Python package.
Waser advocates for using end-to-end workflow tools like Hatch to simplify the learning curve, arguing that a consistent, low-cognitive-load approach helps new users feel empowered and included in the community.
The session concludes with a call to action for the community to support one another, moderate technical debates to avoid alienating newcomers, and focus on providing clear, accessible resources that make the Python packaging journey less intimidating and more collaborative.
