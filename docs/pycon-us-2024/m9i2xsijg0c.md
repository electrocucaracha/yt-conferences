# Summary

In a presentation at PyCon, Todd Copion from Amazon discusses the importance of using diagrams to effectively communicate complex technical ideas, arguing that current diagramming practices are often flat, confusing, and repetitive.
He outlines key graphic design fundamentals—hierarchy, structure, contrast, color, space, and variety—that are essential for creating clear and visually appealing visuals.
The talk demonstrates how Python libraries such as `diagrams` (Minigrammer), `plotly`, and `pyflow` can automate the generation of professional architecture charts and Sankey diagrams from simple code, while also introducing the C4 model and Mermaid as robust frameworks for software architecture visualization.
Copion emphasizes that good diagrams serve as excellent documentation, advocating for a workflow where code generates the base structure and tools like Draw.io or Excalidraw are used for final polishing.
He concludes by urging developers to adopt a "beautiful is better than ugly" mindset, encouraging them to use common formats, avoid excessive clutter, and specifically refrain from using Visio to ensure their technical communication is clear, concise, and useful.
