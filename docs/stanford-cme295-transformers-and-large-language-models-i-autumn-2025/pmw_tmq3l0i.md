# Summary

This lecture introduces LLM preference tuning as a critical third step following pre-training and supervised fine-tuning (SFT), aimed at aligning model outputs with human preferences regarding tone, safety, and helpfulness.
The process begins with collecting pairwise preference data, where human raters or automated judges compare two model responses to a prompt to identify the preferred output.
To implement this alignment, the lecture details Reinforcement Learning from Human Feedback (RLHF), a two-stage method that first trains a reward model using the Bradley-Terry formulation to score responses, and then optimizes the LLM policy via Proximal Policy Optimization (PPO) to maximize rewards while constraining deviation from the base model to prevent reward hacking and catastrophic forgetting.
As an alternative to the complex and resource-intensive RLHF pipeline, the lecture presents Direct Preference Optimization (DPO), a supervised learning approach that directly optimizes the policy using preference pairs without requiring a separate reward model or reinforcement learning loop.
While PPO generally yields higher performance, DPO offers a simpler, more stable training process with lower computational overhead, making it a practical choice for many applications despite potential distribution shift issues.
