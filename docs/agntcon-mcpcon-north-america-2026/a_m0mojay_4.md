# Summary

Anthropic reports that MCP tool calls within its Claude products have grown sixteenfold since April, reaching approximately two billion weekly calls across the entire Claude family, including web, desktop, mobile, and API platforms.
This growth is facilitated by a unified directory containing over 6,000 listings for MCP connectors and plugins, which serves as a central discovery surface for users and developers alike.
The platform highlights significant adoption by major companies such as Atlassian, monday.com, and Linear, whose usage metrics have increased substantially through their Claude MCP integrations.
To build for this ecosystem, developers are advised to create remote MCP servers, package them as plugins with skills, and submit them to the directory, which ensures safety through rigorous scanning and review.
Additionally, Anthropic emphasizes the importance of integrating enterprise managed authentication via the ID Jack standard and supporting agentic communication features like elicitations and events to provide a richer, interactive user experience within Claude.
