# Summary

Lucas introduces Buzz as a collaborative workspace designed to solve the inefficiencies of manually shuffling information between AI agents and traditional communication tools like Slack.
He highlights key features such as open-source sovereignty, model agnosticism, and the ability for agents to have distinct identities and permissions within shared channels.
Morgan then leads a hands-on onboarding session where participants download the app, join a feedback community, and create agents using harnesses like Goose or Claude Code.
The group collaboratively builds and deploys mini-games into a shared "Buzz Arcade," demonstrating the platform's real-time multi-agent and human collaboration capabilities.
The session concludes with a Q&A covering advanced topics like agent-to-agent communication, skill management, and the underlying Nostr protocol, emphasizing Buzz’s goal of centralizing all work context in a single, open environment.
