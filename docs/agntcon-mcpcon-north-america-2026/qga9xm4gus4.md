# Summary

DataDog leverages its extensive history of production outages to enhance AI-driven software development, addressing the challenge of managing over 50,000 monthly pull requests generated by coding agents.
By analyzing incidents, the company extracts reliability invariants and organizes them into "packs" that serve as rules for agentic code review and proactive remediation.
To support this, DataDog maintains a dataset called Doom, which is used to benchmark external agents, detect model drift, and fine-tune an internal risk-scoring model that identifies high-risk changes.
This risk score calibrates the depth of AI review, allowing low-risk changes to be auto-approved while high-risk ones undergo deep analysis by multiple competing agents and human oversight.
Ultimately, this system reduces the severity of incidents and integrates feedback directly into coding sessions, ensuring that outage knowledge is continuously transformed into durable, automated quality controls.
