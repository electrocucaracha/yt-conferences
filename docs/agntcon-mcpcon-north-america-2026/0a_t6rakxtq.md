# Summary

The speaker outlines the evolution of agentic systems, noting that while 2025 focused on coding agents, 2026 will see models autonomously handle long-horizon general knowledge tasks that require robust connectivity and open standards.
To support this shift, the Model Context Protocol (MCP) is expanding beyond simple tool calling to include agentic messaging, richer semantics, and improved authorization, with recent milestones including the adoption of stateless servers and the donation of agent skills to the Agentic Foundation.
Key new features announced include MCP tasks, which enable asynchronous long-running operations, and MCP events, allowing servers to proactively push updates to clients.
Additionally, the speaker highlights the upcoming support for elicitation in Claude, a feature that guarantees human interaction for critical actions like confirmations or payments, and emphasizes the importance of community collaboration to build a seamless connectivity layer for future agentic applications.
