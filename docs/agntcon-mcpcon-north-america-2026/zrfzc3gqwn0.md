# Summary

The Secure Agentic Framework (SAF), recently transferred to the OpenSSF, is a vendor-neutral security taxonomy designed to mitigate risks in agentic AI applications by mapping attack techniques to established standards like MITRE ATT&CK, SOC 2, and HIPAA.
Developed by Frederick Coutsier, Sarah Evans, Laura Gazelli, and Jay White, the framework aims to prevent GRC bottlenecks by providing a rigorous, enumerated list of risks and mitigations that empower security teams to validate AI systems without acting as innovation blockers.
The presentation highlighted "Prompt Escapes," a Python-based teaching tool that simulates insecure travel sites to help users learn about and defend against prompt injection and tool poisoning attacks.
Additionally, Jay White demonstrated a platform-agnostic MCP skill that operationalizes the SAF by analyzing server configurations and agent architectures to identify high-risk combinations, such as the "lethal trifecta" of private data access, untrusted input, and external communication capabilities.
The team emphasized the framework’s extensibility to other protocols like Kubernetes and A2A, inviting community contributions to expand its coverage and integrate with emerging compliance matrices as AI adoption accelerates.
