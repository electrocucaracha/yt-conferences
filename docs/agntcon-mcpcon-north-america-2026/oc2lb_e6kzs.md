# Summary

Liad, co-creator of the MCP apps spec and co-founder of the Aura research lab, presents a vision for the "agentic web," where personal assistants serve as the primary entry point to the internet rather than traditional browsers.
He explains that MCP apps allow businesses to send interactive, branded user interfaces directly into AI chat assistants, solving the "last mile" of interaction by enabling agents to convey user intent without forcing users to navigate complex, human-centric sites.
This shift is already impacting major platforms like Shopify and Walmart, which are opening their services to agents, while others block them to protect human-driven ad models.
Liad argues that human-designed interfaces are inefficient for agents, advocating for a "nearly headless web" where agents handle most tasks and only present relevant UI chunks to users.
To support this transition, Aura conducts real-world agent benchmarks to assess "agent readiness," revealing that many services are not optimized for non-human traffic.
The talk concludes by highlighting emerging standards for discovery and payments, noting that while e-commerce and productivity tools are rapidly adapting to agent-first experiences, social media and advertising models face significant disruption as trust in personal assistants grows.
