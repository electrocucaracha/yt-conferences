# Summary

Sudheera Vanguri from Arm presents a comprehensive overview of agentic AI, arguing that it is becoming the defining workload of the current generation by abstracting application complexity and driving a sevenfold increase in AI-generated tokens compared to human output.
The presentation identifies five key use case archetypes—software engineering, enterprise automation, scientific research, personal assistants, and robotics—each creating distinct CPU signatures that span from cloud infrastructure to edge devices.
Vanguri explains that the software stack has shifted from stateless interactions to complex, stateful orchestration, requiring CPUs to handle critical tasks such as tool execution, sandbox management, and agent coordination, while accelerators focus on heavy reasoning and matrix multiplication.
To address the lack of industry standards for measuring this new paradigm, Arm has collaborated with partners like OpenAI, Meta, and Fujitsu to develop a benchmarking framework that evaluates end-to-end system efficiency rather than isolated component performance.
The session concludes with the release of a white paper demonstrating that Arm’s AGI CPU achieves 2x performance per rack compared to competitors, highlighting the evolving role of CPUs in ensuring efficient, scalable, and standardized agentic AI infrastructure.
