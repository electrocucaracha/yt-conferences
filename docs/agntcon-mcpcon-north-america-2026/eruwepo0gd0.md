# Summary

This panel discussion, featuring experts from Google, Anthropic, and the MCP committee, explores the convergence of MCP Apps and Web MCP as complementary standards for enhancing agent-user interactions.
MCP Apps allow servers to send interactive UI components directly into chat interfaces, preserving brand identity and leveraging user familiarity, while Web MCP provides a standardized API for agents to interact directly with web frontend code, bypassing clunky DOM manipulation.
The speakers highlight that these technologies are not mutually exclusive; Web MCP can be embedded within MCP Apps to allow agents to control UI elements, and MCP Apps can be returned by Web MCP tools to provide visual feedback during headless browsing.
Currently in origin trials and early adoption phases, these standards are being developed in collaboration with major browsers and model vendors to ensure broad compatibility and to address critical challenges such as authentication, analytics, and accessibility.
The session concludes by emphasizing the potential of these frameworks to redefine web accessibility and create a more efficient, unified ecosystem for agentic web interactions.
