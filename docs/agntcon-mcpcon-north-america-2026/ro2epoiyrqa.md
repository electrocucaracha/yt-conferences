# Summary

Tadas presenta la iniciativa del catálogo de IA, un estándar colaborativo diseñado para descentralizar el descubrimiento y la instalación de artefactos de IA como servidores MCP, permitiendo que los usuarios encuentren e instalen capacidades sobre la marcha sin abandonar sus sesiones de agente.
Actualmente, el descubrimiento de estos artefactos es un proceso manual y fragmentado que requiere búsquedas en Google, GitHub o registros internos, lo cual es tedioso tanto para usuarios finales como para proveedores y equipos de TI.
El catálogo de IA funciona como un formato estructurado que apunta a ubicaciones conocidas en sitios web (.well-known/ai-catalog.json), permitiendo que cualquier cliente que cumpla con el estándar descubra e instale fácilmente herramientas.
El proyecto incluye características como catálogos federados para empresas y manifiestos de confianza que verifican atributos de seguridad y cumplimiento, creando un ecosistema donde diferentes actores (editores, proveedores, colaboradores y catálogos) trabajan conjuntamente para proporcionar una experiencia de usuario fluida y elegante.
