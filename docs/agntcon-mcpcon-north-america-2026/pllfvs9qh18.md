# Summary

Chris, CEO and co-founder of Gas City Inc., presents a talk on the evolution from "vibe coding" to structured, orchestrator-based software factories.
He illustrates the limitations of unstructured AI agents through a personal anecdote where an agent’s failure to follow network best practices caused an IP conflict, highlighting the need for deterministic workflows and guardrails.
Gas City is an open-source platform built on Beads, a vendor-neutral durable task manager, that provides a deterministic orchestrator to drive various CLI coding agents like Claude Code and Codex.
The system functions as an "agentic operating system," where agents act as processes executing work defined by Beads, enabling applications such as high-quality software production, company management, and healthcare solutions.
By leveraging recursive self-improvement (RSI) to analyze run data and optimize model usage, Gas City has reduced token consumption by 40% while maintaining quality.
The company offers both open-source tools and commercial products like Beads Team Server and Gas Works for teams seeking shared, scalable agent orchestration, ultimately aiming to empower developers by providing robust infrastructure for building complex AI-driven applications.
