# Summary

The speaker emphasizes that organizations are rapidly deploying agentic workloads, necessitating a fundamental shift toward open-source infrastructure to support these new demands.
To address this, the presentation introduces a comprehensive agentic infrastructure stack built on Kubernetes, featuring projects like Agent Substrate for sandboxing and scaling millions of agent sessions, and Agent Gateway to manage complex agent-to-agent and tool traffic.
Additionally, Agent Registry and Agent Desktop are presented as solutions to provide unified governance, inventory, and policy management across diverse cloud environments and local developer harnesses, ensuring visibility into shadow AI.
The discussion then pivots to security, introducing Agent Shield, a new open-source project designed to handle the evolving threat landscape where attackers are often autonomous agents rather than humans.
Agent Shield employs a continuous pipeline to discover services, map lateral movement risks, and automatically generate and evaluate security policies, providing a defense-in-depth approach that can remediate issues automatically or guide human intervention.
