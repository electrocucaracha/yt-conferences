# Summary

The speaker from AWS’s Hydra team introduces the concept of universal properties as a new paradigm for ensuring correctness in agent-written software.
Unlike unit tests or formal specifications that target specific inputs, universal properties are general specifications that apply to any application, such as Rust’s borrow checker preventing concurrent mutable access or React’s guarantee that incremental re-renders match fresh renders.
These properties are particularly valuable in agentic development because they are defined once and reused across tasks, placing them outside the agent’s trust boundary and acting as reliable guardrails against unpredictable agent behavior.
The team demonstrates this approach through Hydro, a Rust framework that catches distributed systems bugs via type checking, and Infinity, an open-source runtime that enforces observational equivalence for highly concurrent agents.
By identifying, formalizing, and enforcing these cross-cutting properties through strong types and API design, developers can significantly increase trust in the correctness of software generated by autonomous agents.
