# Summary

Sara Drasner, a distinguished engineer at Google, presents the evolution of the web in the age of AI, arguing that the platform must adapt to non-deterministic actors like AI agents while maintaining its open and collaborative nature.
She highlights critical security challenges, such as prompt injection attacks, and advocates for a multi-layered defense strategy using techniques like origin restriction, agent profiling, and content spotlighting to protect user data.
A central focus of her talk is WebMCP, a new standard that allows web developers to expose structured tools and schemas to agents, replacing inefficient and fragile DOM scraping with deterministic, observable interactions.
Drasner demonstrates how WebMCP enhances productivity, accessibility, and progressive enhancement, noting that it is currently in an origin trial phase with active adoption by major e-commerce platforms and browser vendors.
She concludes by distinguishing WebMCP from server-side MCP, emphasizing that they are complementary technologies that can work together to create a more robust and secure web ecosystem.
