# Summary

Buzz is an open-source application developed by Block that unifies human teams, AI agents, and projects into a single collaborative system, leveraging a shared messaging protocol to streamline decision-making and task delegation.
The platform, which has already garnered 80,000 communities and 36,000 GitHub stars, is transitioning from a developer preview to a 1.0 release scheduled for November, featuring a beta version available for immediate use.
Key technical innovations include a robust identity system where agents are attested by users to gain specific permissions without impersonating humans, and a unified backend "relay" that consolidates all conversations and agent actions into a single stream of context for improved AI comprehension.
Additionally, Buzz introduces a plugin architecture that allows users to customize the user interface on the fly and collaborate on shared tools, such as real-time task trackers, directly within the messaging environment.
