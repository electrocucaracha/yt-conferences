# Summary

Facila, a member of the CNCF TOC and cloud native developer at Ericson, is joined by FA to discuss how Easy Saves Birthday, a book about Kubernetes concepts, uses service mesh to demonstrate security features.
The story follows Captain Cube's birthday celebration, where pirates try to steal unattended invitation cards, highlighting the importance of identity verification, access control, observability, and traffic management in securing cloud environments.
A live demo showcases the deployment of Easy Saves Birthday on a Kubernetes cluster, demonstrating how service mesh enables secure communication between applications and verifies identities before allowing data transmission securely.
