# Summary

The Flux project is a graduated project in the Cloud Native Computing Foundation (CNCF) that addresses various needs of CI/CD systems, including progressive delivery, automation, reliability, security, and scalability.
As a community maintainer and user of Helix, Tommo Nakahara highlights the importance of Flux's design, which has been adopted by many enterprises, including financial institutions, healthcare, and government organizations.
With its multi-tenancy, multicluster capabilities, and integration with Kubernetes and cluster API, Flux provides a secure and scalable solution for CI/CD systems, making it an industry standard term in the field.
