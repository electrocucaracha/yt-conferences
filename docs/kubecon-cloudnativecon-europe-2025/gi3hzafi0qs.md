# Summary

Joe Cutner and Terrence Lee, co-founders of the Cloud Native Build Packs project, discuss container builds at scale with cloud-native build packs.
These tools turn application source code into container images without needing Docker files, providing features like caching mechanisms, reproducible builds, and metadata for inspecting layers.
By using rebase, organizations can avoid rebuilding entire images when making changes to base images, significantly reducing costs and deployment times.
The project offers a CLI called "pack" for getting started, as well as pre-built builders with existing build packs available for use.
