# Summary

Ariel discusses the limitations of using infrastructure as code tools like Crossplane and Argo CD for managing critical internal systems, such as databases and custom services like secrets management and feature flag management.
These unmanaged services pose a challenge due to lack of standardization, versioning, audit logs, and visibility into resource ownership.
To address this, Ariel created Provado HTTP, a tool that enables users to define API calls as crossplane managed resources, allowing for the management of any API with a single YAML file.
