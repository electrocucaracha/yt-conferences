# Summary

Vish Abrams, chief architect at Heroku, discusses workload identity, a 12-factor approach to secure resource access.
Workload identity is a unique identity assigned to a workload for secure resource access, such as an app developer's application and backend APIs.
The 12-factor manifesto defines a contract between an application developer and a platform developer or application and platform.
Heroku aims to standardize workload identity through a CLI that acts as a polyfill, allowing developers to use existing standards like OIDC and X509 for authentication.
This simplifies development across platforms, removing the complexity of managing credentials from apps.
The goal is to get community support before implementing it internally, ensuring standardization and safety.
