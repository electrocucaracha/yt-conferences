# Summary

Here is a summary of the video transcript in 3-5 sentences: Leila, a Site Reliability Engineer at Shopify, presented a project where they improved Elastic Search indexing performance and reliability by using dedicated node pools automatically scaled by Kada scalers.
The goal was to reduce infrastructure costs while maintaining high availability and resilience for Shopify's search platform, which processes over 58 petabytes of data during the Black Friday Cyber Monday week.
By separating real-time and reindexing workloads on different Kubernetes node pools, Shopify was able to scale up and down efficiently, reducing CPU cores and memory usage by 58% and 15%, respectively, and saving 43% in infrastructure costs.
