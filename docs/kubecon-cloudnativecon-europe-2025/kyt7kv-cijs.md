# Summary

The Psyllium project has made significant advancements in cloud-native networking, observability, and security.
As a CNI (Container Network Interface) plugin for Kubernetes, it leverages EVPF (Extended Berkeley Packet Filter) technology to provide a flexible and scalable data plane.
The project has expanded to include features like cluster mesh, egress gateway, and BGP gateway API, making it a popular choice among cloud-native users.
With the release of Psyllium 1.17, new features such as quality-of-service (QoS) for guaranteed burstable or best-effort network traffic have been added.
The project has also gained traction with its scalability improvements, including support for large clusters and high pod churn rates.
Additionally, the Tetragonon project, a separate initiative under the Psyllium umbrella, provides advanced security capabilities using ebpf (Extended Berkeley Packet Filter) technology.
