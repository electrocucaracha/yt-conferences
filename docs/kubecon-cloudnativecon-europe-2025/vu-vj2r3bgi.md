# Summary

The End User Technical Advisory Board (TAB) is a governance body of the Cloud Native Computing Foundation (CNCF), aiming to complement the Technical Oversight Committee and Governing Board with an end-user-centric perspective.
The TAB was created to address the need for more user feedback and input in the ecosystem, particularly in areas such as reference architectures, project health, and maturity levels.
Members, including Alorita Sharma, Joseph Sandal, Katie Gamji, Ricardo, and Ahmed Pars, share their experiences and insights on the TAB's role and challenges, highlighting the importance of end user feedback and collaboration to drive innovation and growth in the CNCF ecosystem.
