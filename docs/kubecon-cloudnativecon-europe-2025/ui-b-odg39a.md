# Summary

Jacob from Haroxy Technologies discusses the security risks of Large Language Models (LLMs) and proposes using an AI gateway to mitigate these risks.
He explains that current LLMs are vulnerable to prompt attacks, such as time bandit attacks, which can be mitigated by adding prompt security to the AI gateway.
However, Jacob notes that running these models within an AI gateway is slow, with processing times ranging from 150-200 milliseconds for a single prompt, and even slower when running multiple prompts in parallel.
He concludes that innovation is needed to develop new techniques and tools to secure LLMs in load balancers.
