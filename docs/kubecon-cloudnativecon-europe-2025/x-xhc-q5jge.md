# Summary

The six storage group, led by Yan Shafranic and Shinyang, is a loose collective of people working on Kubernetes storage APIs, including persistent volume claims (PVCs), persistent volumes (PVs), and storage classes.
They maintain kubernetes storage APIs and code behind them, as well as CSI drivers for various storage backends like NFS, iSCSI, and fiber channel.
The group is also designing a container object storage interface to bring bucket and object storage into Kubernetes.
They are working on several features, including generic data populs, PV reclaim policy, and warning expansion, targeting GA in 1.33 release.
The group welcomes contributors and has resources available for those interested in getting involved.
