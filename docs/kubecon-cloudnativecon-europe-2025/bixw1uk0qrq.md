# Summary

The National Institute for Nuclear Physics in Italy, along with CERN's Open Lab, has developed an engine for digital twins that serves multiple communities and shares resources across different providers.
The Interlink project aims to create a platform capable of supporting various use cases and frameworks while offloading tasks onto different backends.
To achieve this, the team uses Kubernetes as the main interface, merging it with other technologies like singularity containers.
This allows users to access Kubernetes without compromising on performance or security.
The system also includes features like reproducible results, composible software, and universal type systems, making it suitable for scientific and enterprise use cases.
