# Summary

Schlomi from Planet Scale introduces unlimited scaling in Vitess, an open-source CNCF project that runs on top of MyScale.
Vitess is used by companies like Cash App, Cashup blocks, and GitHub to serve millions of queries per second out of a relational database.
It achieves scale through custom or configurable sharding keys, allowing users to reshard data as it grows and fine-tune their sharding scheme to match application query patterns, all managed online with zero downtime.
