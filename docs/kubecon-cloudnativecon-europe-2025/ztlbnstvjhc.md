# Summary

The Ingress Engine X project has been facing several security vulnerabilities, including CVE-98, which is a critical unauthenticated remote code execution vulnerability.
The project's maintainers have announced plans to transition out of maintenance mode and migrate to the Gateway API, with the goal of providing a more secure and stable solution.
However, this migration will require significant changes and may not support all existing features, including some annotations and configuration options.
The maintainers are seeking feedback from the community on which features should be prioritized for support in the new Gateway API implementation.
