# Summary

The Ratify project is a sandbox verification engine that safeguards the cloud-native secure supply chain, supporting signature and cosign verification for container images.
It has been adopted by major cloud vendors and offers three key scenarios: integrating with Gatekeeper for policy control, integrating with Containerd at runtime to validate signatures or container images, and using it in CI/CD systems to enforce policies on supply chain-related artifacts like vulnerability reports.
Ratify uses attestations, signed statements that ensure integrity and authenticity, which are important for verifying the trustworthiness of container images beyond just their signatures.
