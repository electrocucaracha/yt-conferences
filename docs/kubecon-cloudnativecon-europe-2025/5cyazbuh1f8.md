# Summary

The speaker, Phil Henderson, discusses API management in the CRD world and Linkerd's approach.
Linkerd is a service mesh that brings security, reliability, and observability to workloads without exceptions.
It uses shared CRDs, which are simple and easy to manage, but can be challenging due to versioning issues and Kubernetes' limitations.
The key takeaway is that APIs should be tailored for humans who need them, not just developers or users.
