# Summary

Andres Agar, a product manager at Octa, introduces Open FJ, an authorization system for developers inspired by Google's research paper on relationship-based access control.
It allows defining entities and relationships to implement generic authorization for any use case, with tools such as APIs, SDKs, and CLIs provided by Octa.
The system is currently in the sandbox stage, maintained mostly by Octa with help from Graphana Labs, and has gained traction with 197 repositories on GitHub showcasing community-built demos, providers, and adopters like Godaddy, Docker, and startups using Open FJ for authorization.
