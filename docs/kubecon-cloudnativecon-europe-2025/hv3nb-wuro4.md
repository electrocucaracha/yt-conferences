# Summary

Mark Tudori and Mario Matias from Graphana Labs presented on using EVPF (eBPF) for non-invasive instant network monitoring.
They explained how EVPF allows for basic information at the network level, such as source and destination IP addresses and ports, but also enables more advanced features like application-level metrics and tracing.
The team demonstrated how EVPF can be used to track Kubernetes services and applications, providing insights into network traffic and performance.
By leveraging EVPF, Graphana Labs aims to provide a comprehensive platform for network monitoring and observability.
