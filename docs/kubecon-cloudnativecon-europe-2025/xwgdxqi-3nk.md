# Summary

The Cubert upstream CI system has undergone significant changes to improve scalability, with a focus on community involvement and collaboration.
The introduction of SIGs (Special Interest Groups) and SIG chairs aims to distribute workload and enhance decision-making processes.
A new design proposal process called VAP (Virtualization Enhancement Process) was implemented to ensure more efficient testing and feedback loops.
Cubert 6 Scale has integrated Quark, a lightweight tool for measuring performance and scale of the control plane, allowing for cost-effective scaling and visibility into scalability bugs.
Future work includes refining simulation tests to mimic real-world workloads and exploring alternative architectures, such as CubeMark, to enhance testing capabilities.
