# Summary

Wizo L from Dolot discusses the latest updates on the SPAR project, an all-in-one Singi solution that supports RDMA network and provides features like observability and right limiting.
The current challenges with Singi annotation configuration and complex network scheduling requirements are addressed by introducing a DIA implementation that can allocate network interfaces based on diversified strategies.
This implementation allows for future range network scheduling strategies using selectors in the resource claim object, enabling more efficient allocation of RDMA devices to ports with specific GPU affinity requirements.
