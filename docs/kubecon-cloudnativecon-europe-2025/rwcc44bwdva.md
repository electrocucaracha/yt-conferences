# Summary

The SIG instrumentation team at Kubernetes aims to provide best practices and tools for component owners to instrument their components using signals such as metrics, traces, logs, and events.
The team has developed various projects, including the usage metrics collector, KSM (Kubernetes Signal Metrics), and CRSM (Custom Resource State Metrics), which decouple custom resource state from Kubernetes signal metrics.
These projects enable extensible dissolvers for metrics generation, allowing users to define their own metric families using languages like Cell.
The team also provides documentation, tutorials, and community resources to help contributors get started with instrumentation.
