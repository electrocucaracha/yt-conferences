# Summary

The Observability Tag, in collaboration with Google, aims to standardize a query language for observability data, focusing on SQL as the best convergence point.
The goal is to reduce costs associated with onboarding and training users, while facilitating federated queries and reducing verbosity.
Pipe syntax, launched by Google, is an example of how this can be achieved, making it easier to write queries and improve operational efficiency.
The collaboration between Google and CNCF aims to align research, unify syntax, and share existing work to create a unified standard for observability query languages.
