# Summary

Katie Ganji, Senior Engineer at Apple, introduces Apple Intelligence, a personalized intelligence system that brings powerful generative models to iPhone, iPad, and Mac devices.
Designed with privacy protection at every step, Apple Intelligence processes tasks locally on the device but requires additional processing power through private Cloud Compute (PCC), which leverages Swift programming language for security and high performance.
PCC is an example of how Apple invests in open-source technologies, drawing from the security properties of Swift to run software with transparency built-in.
