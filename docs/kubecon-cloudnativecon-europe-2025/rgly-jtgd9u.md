# Summary

Luca, a maintainer of Falco, introduces the project as a graduated CNCF project that monitors infrastructure for security events by installing it on clusters, nodes, and containerized environments.
Falco uses simple rules based on Linux system calls to alert users of potential security threats, providing context about the cluster, cloud infrastructure, and surrounding events.
The project has evolved beyond its initial kernel-based approach, allowing users to ingest events from various sources and output them to multiple places, making it accessible to a wide range of users, including those who may not be experts in system calls.
