# Summary

The presentation discusses dynamic resource allocation for networking in Kubernetes, specifically addressing the limitations of the current model and introducing a new approach called Dynamic Resource Allocation (DRA).
DRA allows users to request any type of resource, including network interfaces, and enables more flexible and efficient use of resources.
The presentation also touches on device plugins, which enable mounting physical devices on nodes for workloads, and introduces a new API for requesting resources, including network interfaces.
A demo is shown, where 15 pods are scheduled to request a specific MAC address interface, demonstrating the feasibility of DRA in practice.
