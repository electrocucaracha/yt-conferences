# Summary

Andy Anderson from IBM Red Hat introduced Coupellar, a tool to manage fleets of Kubernetes clusters with workloads, making remote workload deployment easier.
By centralizing workload definition in a "Coupellar core," users can deploy workloads using existing tools like Helm and Argo.
This allows for disconnected operations by creating a control plane within another control plane, reducing the number of API resources from 300 to 40, enabling seamless interaction with various remote devices.
