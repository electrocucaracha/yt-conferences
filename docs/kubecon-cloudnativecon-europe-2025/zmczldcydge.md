# Summary

Millennium BCP leverages Radius to empower developer and operator collaboration by providing an application model that allows platform engineers to build IDPs better serving their customers.
Radius is a cloud-native application platform that enables developers to define an application once and deploy it across on-premise, AWS, and Azure environments.
The platform features GitOps integration, extensibility at the resource level, and a customizable application graph, making it easier for teams to collaborate and deploy applications efficiently.
By adopting Radius, companies can avoid redundancy and get value from collaborating with the open-source community, as the platform is now being recognized as a general-purpose requirement for most IDPs.
