# Summary

Cryo, a lightweight container runtime built specifically for Kubernetes, has been optimized for Kubernetes and follows the Kubernetes release cycle.
It is OCI compatible, allowing for seamless integration with other container initiatives.
Cryo 1.33 will feature support for OCI artifacts, enabling users to pull, list, inspect, and remove artifacts, as well as use them as image volumes, which will enable AI and ML use cases.
This new feature allows for configuration distribution and stacking of container images, making it an exciting development in the world of Cryo.
