# Summary

Lucy and Don Chen from Kubernetes discuss new features in Kubernetes, including "P-level resource" that allows for more flexible resource management at both container and pod levels.
This feature simplifies configurations and reduces the possibility of misconfiguration based on container resource usage exceeding node capability.
They also introduce a new concept called "p-grouping," which groups pods together to enable efficient scheduling of batch workloads, similar to how specialized job schedulers like Slurm work.
Additionally, they discuss the future of Kubernetes, including the need for more workload support and the importance of user feedback in shaping the project's direction.
