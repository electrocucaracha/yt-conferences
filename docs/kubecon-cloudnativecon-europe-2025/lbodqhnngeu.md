# Summary

The Sig Network, responsible for Kubernetes networking components, interfaces, and APIs, has updates on Gateway 1.3, including core support, retry budgets, and listener sets.
Listener sets allow merging multiple gateways or having a large number of listeners in a single gateway.
The team also discusses Ingress Engine X, which is shifting to the new project called "ingate," and plans to support around 55% of its features by the end of the year.
Additionally, updates are provided on Network Policy API, including admin network policy and baseline admin network policy, which are currently in alpha and aim to provide cluster-wide security.
