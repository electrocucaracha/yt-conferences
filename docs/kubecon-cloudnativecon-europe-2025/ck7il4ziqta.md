# Summary

The presenter discusses the testing of large-scale edge computing using KU Edge, a cloud-native edge computing framework designed for edge-cloud collaboration.
The Kubage community has over 8,000 stars and 2,200 forks on GitHub, with more than 1,500 contributors from over 100 countries worldwide.
The framework is built upon native Kubernetes, with a cloud component called Cloud Core and an edge component called Edge Core.
The presenter tests a single-class manager with 100,000 edge nodes and 1 million ports, meeting the SLOs defined by Kubernetes for API coency, latency, and port standup nancy.
The test results show that Kubage can stably support 100,000 edge nodes online and manage over 1 million ports in a production environment, with scalability and reliability features such as an efficient cloud-edge message channel and incremental data push model.
