# Summary

The talk discusses the risks of containers and how to secure them.
The presenters introduce "Squishy Bin," a container with known vulnerabilities, and demonstrate how to improve its security using tools like Trivy, TruffleHog, and Gatekeeper.
They also provide tips for securing containers in production, including ensuring default choices are secure, understanding customer needs, and creating a security advocate program.
The presenters emphasize the importance of making security a priority and encourage attendees to join the conversation on improving Kubernetes security.
