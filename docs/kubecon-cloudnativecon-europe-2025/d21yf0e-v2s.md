# Summary

The video discusses the Cyber Resilience Act (CRA) and its implications on software supply chain security.
The CRA aims to hold creators of software responsible for timely patching and updating, shifting the burden from unpaid open-source maintainers to those selling the software.
This change is necessary due to the increasing number of supply chain attacks, which have compromised various systems, including the NHS blood tests and Cisco Duo.
The speakers emphasize that security will always be one step behind feature delivery and that organizations must operate within this reality.
They introduce Guac (the Graph for Understanding Artifact Composition), an open-source project that helps track software dependencies and vulnerabilities, and demonstrate its use in a live demo to verify a vulnerability in a Kubernetes cluster.
