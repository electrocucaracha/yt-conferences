# Summary

The Notary Project is an open-source initiative addressing software supply chain security concerns, such as ensuring artifacts come from trusted sources and remain unaltered.
It provides standard-based solutions and tools, including support for OCI artifact signatures and two ITF standard formats, to facilitate interoperability and compatibility in cloud environments.
The project has gained traction with major cloud vendors and popular open-source projects, and its new "notation" tool enables signing of arbitrary blob files, providing an additional layer of security for software artifacts.
