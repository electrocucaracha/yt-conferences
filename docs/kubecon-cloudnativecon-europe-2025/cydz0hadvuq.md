# Summary

Here is a summary of the video transcript in 3-5 sentences: Justin Capos and Alan, a software engineer, discuss software supply chain attacks and compliance.
They explain that a software supply chain refers to the process of making software, from development to distribution, and that attackers can cause malicious things to happen by exploiting vulnerabilities in this process.
To address this issue, they introduce "into" (In-to), a project that aims to provide transparency and security in software supply chains through tools like witness and Archive Vista, which help store and validate attestations, and guac, which visualizes and understands artifact compositions.
