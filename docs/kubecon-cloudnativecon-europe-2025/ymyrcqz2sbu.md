# Summary

Bradley Anderson, a community manager at KGB, introduces the project update for KubeCon.
KGB is a global service load balancer that enables applications to be serviced in multiple geographies with low latency, following the Kubernetes operator platform and implemented with a single GS LB CRD.
It provides an independent GSLB capacity to any ingress or service, without dedicated management clusters, and is vendor-neutral and environment-agnostic.
KGB has been around for five years, submitted its incubation app five months ago, and plans to release GCP DNS gateway API in quarter 2, along with a docs overhaul.
