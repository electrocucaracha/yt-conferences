# Summary

The Kubernetes SIG Network project aims to standardize on Gateway API for its network projects, shifting focus from Ingress Engine X due to its growing complexity and maintenance challenges.
Gateway API has been gaining popularity with over 30 implementations and is considered the most collaborative API in Kubernetes history.
The goal is to migrate Ingress Engine X users to Gateway API, which will provide a more portable and secure API across implementations.
A survey will be conducted to understand user needs and prioritize features for implementation.
Temporary slots will be added to support Ingress Engine X compatibility, with plans for at least three releases in 2025 and 2026.
The project aims to make the migration process smoother by providing a better experience and unlocking new capabilities for users.
