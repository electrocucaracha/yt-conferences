# Summary

Jared and Nick from the Crossplane project discuss the latest updates to Crossplane, a cloud-native control plane that allows users to provision and manage resources across multiple cloud providers.
They introduce Composite Resources (CRs), which enable users to compose higher-level abstractions from granular resources, making it easier for developers to self-service and provision resources.
The team also highlights new features in Crossplane v2, including namespaced managed resources, composite resources with a namespace scope, and improved documentation.
Additionally, they discuss the importance of community contributions and invite attendees to get involved.
