# Summary

Ilia from Spotify discusses the challenges of cloud cost management and how AI assistance can help.
Traditional cost analysis is a manual process with significant technical expertise gaps, inefficiencies, and errors.
To address these challenges, Ilia's team developed an intelligent system that uses LLMs to generate SQL queries, execute them in sandbox environments, and leverage Google search APIs for external knowledge.
The system also features task planning architecture, verification, and replanning capabilities, achieving 58% accuracy in evaluating real user questions compared to a baseline approach of 22%.
