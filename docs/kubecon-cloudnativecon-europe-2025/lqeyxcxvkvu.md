# Summary

Rasco Kuan, an entrepreneur from Israel, discusses the importance of access control for AI agents at CubeCon London.
He references Isaac Asimov's three laws of robotics and notes that current AI systems lack robust access controls, leading to security risks.
Kuan introduces the four-parameter framework for securing AI access control, which includes prompt filtering, rag data protection, secure external access, and response enforcement.
He demonstrates this framework using Pentic AI and Kubernetes, showcasing how it can be applied to various projects.
The key takeaway is that AI agents require strong identity and access controls, and the four-parameter framework provides a step-by-step approach to securing these systems.
