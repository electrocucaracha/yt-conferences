# Summary

The gRPC project has seen significant growth, with 1.7 million downloads per week for Java and Apache Maven, 24 million weekly downloads for Python, and 13 million weekly downloads for Node.js.
The documentation efforts have been improved, with the addition of new sections, videos, and code examples.
A new feature called XDS global rate limiting has been introduced, allowing gRPC servers to implement rate limiting functionality directly in the gRPC library.
Additionally, the project is working on improving protocol buffer development, including a new edition called Protobuff 2023 that combines features from Proto2 and Proto3, and a new command-line tool called Protoiller to help with migrating files and messages to new values.
The gRPC team welcomes feedback and collaboration from the community, particularly regarding open telemetry semantic conventions.
