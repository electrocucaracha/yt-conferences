# Summary

Limitri Karakasilis, a maintainer of the Chyros project, defines a single-purpose operating system as one that limits user actions based on known workload to enhance security and reduce attack surfaces.
Over the past 12 months, the Chyros team has made significant progress, including becoming a CNCF sandbox project, implementing trusted boot with secure boot, measured boot, and full disk encryption, and consolidating tooling for easier distribution and edge device support.
The project also features peer-to-peer technology, remote key management, and system DC extensions for dynamic image building, with publicly accessible cloud images available on AWS, Google Cloud, and Azure.
