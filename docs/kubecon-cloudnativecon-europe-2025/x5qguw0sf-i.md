# Summary

Ben, a software engineer at Kusari, discusses two projects: Guac and Cubescape.
Guac is an open-source project that provides a GraphQL API for analyzing supply chain data from various sources, including SBOMs (Software Bill of Materials).
Cubescape is a Kubernetes security platform that uses eBPF to monitor container activity and detect vulnerabilities in images.
Ben showcases how Guac can integrate with Cubescape's filtered sbomb objects to provide more accurate vulnerability scanning and package management.
