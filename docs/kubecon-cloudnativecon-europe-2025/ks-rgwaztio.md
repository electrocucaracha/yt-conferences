# Summary

The speaker, Fiona, introduces herself as a software engineer at Grafana Labs and discusses the latest updates in Prometheus V3, including a new UI with improved compatibility, native histograms for more efficient data storage, and remote write 2.0 for enhanced network efficiency and support for OTLP signals.
The talk also covers breaking changes, such as changes to PromQL and scraping protocols, and highlights community governance updates, including the addition of new team members and a contributor ladder framework.
Fiona invites the audience to contribute to these efforts and explore various channels for getting involved.
