# Summary

The speaker, Alex Jones, introduces Kate's GBT (Generalized Behavioral Testing), a tool that uses AI-enhanced analysis on codified SRE knowledge to debug and triage issues in Kubernetes clusters.
The tool allows users to scan their cluster, identify health issues, and receive measured guidance on how to fix them.
KGBT comes with 11 interoperable AI backends, custom analyzers, and integration with Prometheus.
Auto remediation is a new feature that uses guard rails to apply fixes based on suggested changes from the AI model.
The tool aims to create zero-touch environments, reducing human interaction in cluster management, and making it easier for junior engineers to work together with KGBT.
