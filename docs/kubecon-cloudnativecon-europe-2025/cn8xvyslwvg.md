# Summary

Falco is a cloud-native runtime security tool that detects security traits and delivers alerts to teams.
It works by monitoring kernel or cloud events, tapping into the kernel using BPF probes or kernel models, and sending events to predefined rules that define anomalous behaviors.
Falco has a strong plug-in system, allowing users to grab data from other sources like Kubernetes logs, Octo, and GitHub Actions.
The tool can deliver alerts to over 50 destinations, including Slack, Kafka, and databases.
