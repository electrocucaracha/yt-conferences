# Summary

Vijay Samuel, a principal MTS architect at eBay, discusses AI-enabled explainers for observability.
He shares his experience with using machine learning (ML) and large language models (LLMs) to improve incident triage and troubleshooting.
Initially, eBay tried to use LLMs to solve complex problems but faced issues with probabilistic responses.
Instead, they developed building block capabilities, including trace explainer, log explainer, metric explainer, and change explainer, which provide deterministic and high-quality explanations for critical paths in traces, logs, and metrics.
These explainers are designed to be modular and can be combined to create more complex workflows, such as dashboard explainers and triage workflows.
