# Summary

The Not Project is a cloud-native security solution that aims to ensure the authenticity and integrity of cloud-native artifacts by providing standard-based solutions and tools.
It supports the OCI standard for managing artifacts across registries and multicloud platforms, as well as IETF standards for signature formats.
The project offers a plug-in framework, allowing users to extend its capabilities with custom plugins.
Not Project has completed its core capabilities for signing and verifying OCI artifacts and is currently working on extending its support to other artifact types, such as binary files and web assembly models.
