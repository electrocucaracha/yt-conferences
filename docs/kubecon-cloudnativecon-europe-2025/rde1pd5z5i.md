# Summary

Li Chong from OPPO introduces Kubas, a cloud-native storage system, and its architecture, which includes a client subsystem, catch subsystem, metadata subsystem, object access zone, and storage subsystem.
The system supports multiple protocols, has two engine storage engines, and achieves strong consistency based on raft and qual.
Li will present three case studies: building AI storage, computing and storage separation in ClearHouse, and compute storage separation with SDK.
