# Summary

Rob Cotch, a deaf principal data engineer at Slalom, discusses the challenges of implementing machine learning workflows for sign language recognition with CubeFlow.
He highlights the need for context and spatial awareness in sign language, which is difficult for AI to recognize compared to voice recognition.
With CubeFlow's end-to-end workflow management system, Rob aims to create a unified platform for automated data processing, versioning, and integration tools, enabling anyone to use it seamlessly.
The demo showcases the complexity of the project, including UI client, inference service, models, and pipelines, with the ultimate goal of improving sign language recognition and accessibility.
