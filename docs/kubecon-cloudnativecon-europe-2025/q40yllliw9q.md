# Summary

The Kubernetes documentation team, led by Da Moan and Natalie Vlatco, discussed the importance of documentation in open-source adoption.
They highlighted that 79% of online readers strictly skim content when it comes to docs, emphasizing the need for scannable text principles, such as subheadings, bullet points, and clear structure.
The team also emphasized the value of community-driven development, encouraging contributors to use the docs and provide feedback.
Additionally, they discussed the need for improvement in their API reference documentation and blog review process, inviting interested individuals to join the Kubernetes Slack channel and contribute to the project.
