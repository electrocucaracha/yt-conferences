# Summary

The speaker, MJ, introduces himself as a maintainer at KCP (Kubernetes Control Plane) and discusses extending Kubernetes Resource Model (KRM) beyond Kubernetes workloads to reach KRM++.
He explains that KCP aims to provide a single platform for managing multiple Kubernetes resources, APIs, and tenants by shifting the API surface out of the Kubernetes cluster.
This allows for stronger multi-tenancy, API management, and interconnectivity between different teams and clusters.
The speaker demonstrates how KCP enables building platforms, such as database-as-a-service, by externalizing APIs and creating a control plane as a service.
