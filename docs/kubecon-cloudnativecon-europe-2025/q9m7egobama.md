# Summary

Copa is a tool that directly patches vulnerabilities in container images by interpreting scanner results and generating a new patch layer on top of the existing container.
It can work without scanning tools like Trivy, instead using package managers for the underlying distribution to install updated packages.
Copa has recently improved with support for Alma Linux, community scanner plugins, customizable tag suffixes, mirrored tooling images to GitHub Container Registry, and better logging support for health packages.
Upcoming features include multi-architecture and bulk image patching with a developer-friendly experience.
