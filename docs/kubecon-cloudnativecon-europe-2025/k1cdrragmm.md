# Summary

The cloud-native networking stack is now complete and optimized, thanks to the donation of Glue to the Cloud Native Computing Foundation (CNCF) as K Gateway.
This completes a crucial component of the CNCF's efforts to standardize cloud-native networking.
Additionally, Ambient Mesh has achieved General Availability (GA), offering cost-efficient, high-performance, and user-friendly service mesh and Kubernetes solutions.
The CNCF community has also developed new tools, including a cost analysis tool and automated zero-downtime migration tool for Ambient Mesh, as well as Gateway API Inference Extensions to support AI workloads.
These developments aim to prepare the infrastructure for the impact of Artificial Intelligence (AI) on the industry.
