# Summary

The presentation discusses running generative AI models on own infrastructure in a secure way, particularly for businesses concerned about data security and compliance.
The speakers, Priya Samuel and Luke Marsden, introduce the concept of hosting LLMs (Large Language Models) on Kubernetes clusters with GPUs or TPUs, which enables better performance, security, and control over data processing.
They showcase two demos: one using Olama, a simple open-source product for testing LLMs, and another using VLM, a more advanced model that can handle complex tasks like API integrations and knowledge retrieval.
The speakers also discuss the importance of testing and evaluating AI models, as well as the development of an AI spec to standardize configuration-based applications in Kubernetes.
