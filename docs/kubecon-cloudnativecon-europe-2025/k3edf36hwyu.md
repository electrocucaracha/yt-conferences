# Summary

The Cloud Native Computing Foundation (CNCF) has established a formal program to represent end-user companies, providing representation on the board and technical boards, as well as opportunities for collaboration, contribution, and learning from each other.
Over 150 organizations are currently part of this community, including Apple, Lockheed Martin, Boeing, and CERN.
The CNCF also hosts an End User Technical Advisory Board, which includes representatives from companies like the New York Times and Adobe.
Additionally, the organization has released a new Tech Radar report focusing on developer experience and observability, and has launched an academic accreditation program to support universities in preparing students for cloud-native technology careers.
