# Summary

The speaker, Jeremy Rickard, a principal software engineer at Microsoft Azure and co-chair of SIG release in the Kubernetes project, discusses container supply chain security with a focus on signing images and verification.
He reminisces about the early days of containers and how they were easy to package and deploy.
However, he notes that DockerHub's rate limits and registry disappearances have made it difficult to maintain carefree experiences.
Rickard proposes using internal registries, verifying signatures, and enforcing policies to secure container supply chains.
He demonstrates this by deploying an application, including a 2017 emoji voting app, using tools like Flux, Kyverno, and Notation.
The deployment includes verification of the signature and scanning for vulnerabilities.
