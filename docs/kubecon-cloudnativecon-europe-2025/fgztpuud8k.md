# Summary

Kendall Rhoden, a product manager at Diagrid, introduces Dapper and Score, two projects aimed at simplifying the development process by abstracting away complexity from developers.
Dapper provides a set of APIs and SDKs that enable developers to consume platform capabilities without rewriting common patterns or implementing complex resiliency logic.
Score is a framework for defining workload specifications, which can be used to deploy applications on various platforms, including Kubernetes.
The combination of Dapper and Score enables developers to focus on writing code that provides value to the business, while the platform handles the underlying infrastructure concerns.
