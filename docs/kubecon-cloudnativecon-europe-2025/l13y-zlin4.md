# Summary

Kaberno, a CNCF incubating project, is a policy engine built for Kubernetes that helps achieve compliance and security requirements through YAML policies.
It works as an admission controller and scanner, validating resources and detecting non-compliance issues.
Kaberno's new release introduces five new policy types: validating, image validating, atestation verification, payload verification, and cleanup policy, which provide more expressive and declarative syntax for writing policies.
These new policy types aim to simplify the API and improve performance while retaining existing features.
