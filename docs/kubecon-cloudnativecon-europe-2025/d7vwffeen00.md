# Summary

Here is a summary of the video transcript in 4 sentences: Tamang from Hi Technologies discusses simplif cloud native security ebl powered encryption in static colorless mesh, specifically focusing on Key Mesh (K Mesh), an open-source project based on CNCF landscape.
K Mesh has two modes: kernel mode and D engine mode, which enable transparent site-color service mesh without passing through proxy layers for improved performance and deployment flexibility.
