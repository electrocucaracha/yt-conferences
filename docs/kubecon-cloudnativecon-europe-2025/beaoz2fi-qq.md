# Summary

Vant, a maintainer of Litmas Chaos, discusses the tool's journey towards CNCF graduation.
Currently used by over 250 enterprise customers, Litmos Chaos has seen a 300% increase in Docker pools and 21 active maintenance releases.
The project has completed two audits: a security audit with fixes for vulnerabilities and an documentation audit that updated obsolete sites and structures.
Future plans include improving code coverage, providing flexible APIs, and integrating with KSGPT and open telemetry.
