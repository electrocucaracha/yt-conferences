# Summary

Jonah Susman, a software engineer at Red Hat, introduces Conveyor AI, a CNCF sandbox project that accelerates legacy migration projects.
Conveyor uses analysis rules to flag code locations for fixing in applications, making it easier to migrate large numbers of applications to cloud-native technology.
Kai, an AI component of Conveyor, utilizes this data to generate recommendations for migrators, leveraging existing analysis data and fine-tuning is not required.
The system provides a chat interface with reasoning behind its choices, allowing users to accept, reject, or modify solutions, and stores data for future improvements.
