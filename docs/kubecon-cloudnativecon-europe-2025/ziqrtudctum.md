# Summary

Hungai from Huawei is a maintainer of the Kamada project, an open-source tool designed for managing applications across multiple Kubernetes clusters.
Similar to Kubernetes, Kamada provides API servers, schedulers, and controller managers to manage clusters, regardless of their origin (cloud provider or data center).
With over 700 contributors and 36 public adopters, including notable companies like Trip.com and Bloomberg, Kamada offers features such as multicluster service discovery and resource view, and has been adopted in production environments for managing large-scale communated clusters.
