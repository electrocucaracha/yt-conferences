# Summary

Jonah Cowell, a maintainer of the Jerger project, introduces himself and explains that he will walk through some key features of Joerger, a distributed tracing system used in microservices architectures.
Distributed tracing is essential for identifying issues and optimizing performance.
Jerger provides tools such as dependency maps, root cause analysis, and metrics monitoring to help users understand their application's behavior.
The project has recently released version 2, which is built on top of OpenTelemetry and offers improved scalability, support for multiple backends, and a more user-friendly interface.
