# Summary

Joshua Packer, a member of the Open Cluster Management steering committee, discusses scheduling AI workload among multiple clusters or fleets of clusters.
Open Cluster Management is a CNCF sandbox project that uses a hub-and-spoke topology to manage clusters and distribute workload using manifest work CRDs.
The system allows for dynamic filtering of clusters based on labels, cluster claims, placement scores, and availability, enabling efficient placement of AI workloads in clusters with suitable resources.
Integrations with Q and federated learning enable the use of GPU resources and processing models on remote fleets, respectively.
