# Summary

Ben Koshi from the Prometheus team welcomes viewers to the Prometheus 3.0 speedrun, highlighting the release's key features.
The new UI is visually appealing, with improved PromQL learning tools, and many feature flags are now enabled by default.
The major version bump marks 7 years of stability for an open-source project in the cloud-native space, with minimal breaking changes.
Prometheus 3.0 also introduces native histograms, improved remote write specs, and enhanced UTF8 support for metric names and labels, setting the stage for future interoperability with Open Telemetry.
