# Summary

The presentation discusses the Volcano project, a cloud-native AI infrastructure that aims to simplify and accelerate high-performance AI and machine learning workloads.
The project focuses on two key trends: resource layer awareness and inter-node topology.
It introduces the concept of "hyper nodes," which abstracts underlying network topology, allowing for better scheduling and resource allocation.
The presentation also covers features such as life cycle management, GPU virtualization, and edge scheduling in multiple cluster environments.
Volcano is an open-source project with a growing community, and its future developments include integrating with the latest work set API and supporting different scheduling policies for various use cases.
