# Summary

Maril Jes, a staff software engineer at Graphfana Labs, discusses how to enhance database observability with Open Telemetry.
He introduces the concept of semantic conventions, which define common attributes and names for spans and metrics across different databases and languages.
The goal is to ensure consistency and ease of use when collecting and sending data to observability vendors.
Maril shares an example using Postgres, where he instruments a simple application and uses the Open Telemetry SDK to collect span and metric data.
He demonstrates how to view and analyze this data in Graphana, including breakdowns by operation type and duration.
The instrumentation is designed to be flexible and customizable, with options for sanitizing sensitive data and opting-in to send confidential information.
