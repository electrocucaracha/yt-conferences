# Kubecon Cloudnativecon Europe 2025

## Executive Overview

KubeCon + CloudNativeCon Europe 2025 in London gathered over 12,500 developers, infrastructure architects, open-source maintainers, and enterprise leaders to mark 10 years of the Cloud Native Computing Foundation (CNCF).
The conference highlighted a critical evolution from foundational cloud-native infrastructure toward intelligent, AI-aware orchestration, production-grade WebAssembly (Wasm) deployments, and highly productized platform engineering.
Organizations are moving beyond basic container scheduling to implement specialized inference gateways, prefix-aware KV cache routing, dynamic device allocation, and disaggregated AI serving topologies.
Concurrently, platform teams are standardizing on internal developer platforms (IDPs), Score/Dapr developer abstractions, and fine-grained authorization (OpenFGA, Cerbos) to deliver Golden Paths across hybrid and multi-cloud environments.
To maintain security and compliance under emerging regulations like the EU Cyber Resilience Act (CRA), industry maintainers emphasized automated software supply chain attestations, VEX feeds, and zero-code eBPF observability.

## Terminology

- **Gateway API Inference Extension**:
  A Kubernetes SIG Network project extending Gateway API to enable model-aware routing, SLA management, and prefix-aware load balancing for LLM inference workloads.

- **Dynamic Resource Allocation (DRA)**:
  A flexible Kubernetes framework providing dynamic, fine-grained allocation and sharing of hardware accelerators like GPUs without static pre-configuration.

- **Prefix-Aware Routing**:
  An inference routing mechanism that directs LLM requests to model servers holding matching prompt prefixes in local KV cache to minimize time-to-first-token.

- **WebAssembly (Wasm) Component Model**:
  A vendor-neutral standard for building modular, sandboxed WebAssembly binaries with language-independent interface definitions (WIT).

- **Cyber Resilience Act (CRA)**:
  European Union legislation establishing mandatory cybersecurity requirements, vulnerability reporting, and supply chain accountability for digital products and open-source stewards.

- **OpenFGA**:
  A Relationship-Based Access Control (ReBAC) authorization engine based on Google's Zanzibar paper that enables fine-grained permission management across applications.

- **eBPF-Powered Observability**:
  Zero-code kernel-level instrumentation using extended Berkeley Packet Filters to capture network, performance, and security telemetry without modifying workload code.

- **VEX (Vulnerability Exploitability eXchange)**:
  A structured, machine-readable format for security advisories that communicates whether a specific vulnerability actually impacts a product in a given execution environment.

## Key Themes & Trends

- **Cloud Native AI and Intelligent Inference Orchestration**:
  Kubernetes is solidifying its role as the global control plane for enterprise AI and LLM workloads.
  Maintainers are advancing dedicated batch schedulers (Kueue, Volcano, YuniKorn, Carmada, Q) and inference controllers (KServe, Gateway API Inference Extension, LLMD) to maximize GPU utilization, support disaggregated prefill/decode serving, and enable prefix-aware KV cache offloading.

- **WebAssembly and Workload Sandboxing**:
  WebAssembly has evolved into a primary cloud-native server runtime and security sandbox.
  Projects like wasmCloud, Cosmonic, Waset, and Envoy Wasm extensions leverage the Wasm Component Model to offer sub-millisecond cold starts, capability-based security, and sandboxed tool execution for autonomous AI agents.

- **Productized Platform Engineering and Golden Paths**:
  Organizations are shifting from ad-hoc DevOps scripts to productized Internal Developer Platforms (IDPs).
  Using abstractions like Score, Dapr, Backstage, Radius, and declarative GitOps frameworks, platform teams establish Golden Paths that reduce developer cognitive load while embedding security, compliance, and cost governance into developer workflows.

- **Supply Chain Security and CRA Readiness**:
  In response to regulatory frameworks like the EU Cyber Resilience Act, cloud-native security focuses on end-to-end artifact provenance.
  Standardization around in-toto attestations, Notary Project artifact signing, Ratify admission verification, VEX vulnerability feeds, and fine-grained authorization (OpenFGA, Cerbos) ensures verifiable software integrity from build to cluster execution.

- **Zero-Code Observability and eBPF Maturity**:
  Observability is shifting toward zero-code, eBPF-based instrumentation (Cilium, Beyla, bpftime) combined with OpenTelemetry semantic standards.
  Integrations across Prometheus 3.0, Jaeger v2, and OpAMP supervisors enable unified tracing, metrics, and logs across complex multi-cloud and AI container deployments without modifying application code.

## Key Takeaways & Strategic Insights

- **Standardize on Open Inference Gateways**:
  Adopt community standards like the Gateway API Inference Extension and KServe to implement prefix-aware routing and KV cache offloading, reducing GPU latency and compute spend.

- **Leverage WebAssembly for Agent Sandboxing & Edge Isolation**:
  Incorporate Wasm sandboxes for AI agent tool calls, edge compute, and untrusted microservices to enforce deny-by-default capability security without full container overhead.

- **Treat Internal Developer Platforms as Products**:
  Structure platform engineering teams around developer experience, offering clear Golden Paths, Score/Dapr abstractions, and automated compliance gates rather than imposing rigid top-down operational mandates.

- **Automate Supply Chain Provenance for Regulatory Readiness**:
  Implement automated build attestation, container signing (Notary/Ratify), and VEX feed integration to ensure compliance with emerging European and global software security regulations.

- **Unify Telemetry with OpenTelemetry and eBPF**:
  Deploy eBPF-based zero-code instrumentation alongside OpenTelemetry semantic conventions to achieve continuous observability across multi-cloud environments and AI inference pipelines.
