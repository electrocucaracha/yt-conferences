# Summary

The speaker, Sna, introduces herself as a senior software engineer at Harness and maintainer of Litmus Chaos.
She explains that Litmus Chaos is a Cloud Native Computing Foundation (CNCF) incubating project that allows users to practice Kubernetes engineering on their cloud-native applications.
The project aims to make Kubernetes engineering secure and accessible.
Over the past few years, Litmus Chaos has undergone significant development, including the launch of Kos Operator, Kos Hub, and Kos Probes.
The project has also added support for GitHub Actions, GitLab Actions, and distributed tracing.
Additionally, Litmus Chaos is planning to add support for Native Kubernetes workflows, Terraform, and Kubernetes connectors.
The speaker concludes by thanking the audience for their attention and invites them to join the Litmus Chaos community on GitHub or Slack.
