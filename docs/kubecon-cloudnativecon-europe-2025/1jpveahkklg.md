# Summary

Tina Silen, a software engineer at Red Hat and contributor of StreamZy, discusses this open-source project that automates the installation and management of Apache Kafka on Kubernetes.
StreamZy provides various operators for running and managing Kafka components, as well as tools to simplify its deployment and operations.
The latest release, 046, removes zookeeper, simplifying cluster maintenance and improving scalability and performance.
Future plans include improving certificate management, integrating self-healing capabilities, and releasing a single API version.
