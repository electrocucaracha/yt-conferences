# Summary

The Kubernetes SIG security team aims to improve the project's security through a community-based approach.
They provide a platform for sharing interests and concerns, collaborate with other SIGs, and organize working sessions to address security issues.
The team has made significant contributions, such as removing outdated security features, maintaining a CVE feed, and running third-party audits.
They also work on improving documentation, including the Kubernetes website's security content, and have initiatives like the go-check project and the official CV feed.
The team welcomes new contributors, offering support and guidance to help them get started, regardless of their experience level.
