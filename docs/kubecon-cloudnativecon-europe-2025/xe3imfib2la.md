# Summary

The speaker, Pray, discusses strategies for getting the best return on investment (ROI) from observability data, particularly when using open telemetry platforms like Signos.
To optimize data, users can employ techniques such as sampling, granular control over processing and filtering at the collector level, and careful attribute selection at the SDK level.
By implementing these strategies, organizations can reduce unnecessary data transmission, lower costs, and improve ROI from their observability efforts.
