# Summary

Mark Lavy discusses the storage track data protection canister project, a 130 sandbox project addressing the growing need for stateful distributed applications on Kubernetes clusters.
As state is increasingly being stored on clusters, backup and recovery become essential, with three steps involved: backup, restore, and disaster recovery.
The Canister framework aims to orchestrate and manage these concerns, providing a top-down approach to application-centric backups, and offers a Helm chart installation method with CRDs (Custom Resource Definitions) for blueprints, action sets, and profiles.
