# Summary

Martin from Kong discusses the latest updates in Kuma, an envoy-based service mesh.
New features include a kind data plane in policies, redesigned inbound policies API, ability to define secrets on zone level, option to exclude policy from sync between zones, and stability improvements.
The new kind data plane simplifies configuration by allowing users to select workloads based on labels, making it easier to apply configurations to specific workloads or single inbounds.
