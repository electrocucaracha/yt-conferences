# Summary

Mario, a software engineer at Red Hat, discusses the introduction of volumes of type image in Kubernetes, a new feature proposed less than a year ago.
This allows users to specify images as volumes that can be mounted in containers and pods, enabling various use cases such as distributing models for AI applications and adding tools like debugging utilities inside containers.
The feature has been introduced as an alpha in Kubernetes 1.33 and will graduate to beta in the next release, with support from Podman, Docker, Cryo, and Containerd.
