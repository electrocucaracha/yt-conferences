# Summary

Mitch Connors, a principal engineer at Microsoft, is giving a talk on ISTO (ISTO Service Mesh Technology Overview) instead of the originally planned title.
He explains that ISTO is a service mesh with three primary functions: managing connectivity between pods, providing security for that connectivity, and offering observability.
The security aspect involves encrypting all connections using FIPS-compliant encryption algorithms, while the observability aspect provides telemetry for every request in the mesh.
Connors highlights the benefits of choosing ISTO for service mesh needs, including its robust community, ease of use, and quick onboarding process.
