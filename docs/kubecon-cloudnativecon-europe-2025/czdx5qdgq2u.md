# Summary

Anish Astana, an engineering manager at Red Hat's Open Shift AI group, and Royal Alex, an engineer at IBM Research, discussed data preparation and processing using Kubernetes.
They introduced the concept of data prep-processing workflows, which typically involve steps such as data duplication, language separation, filtering, and tokenization.
The duo showcased Cubray, a Kubeflow operator that simplifies data processing by providing reusable components and modularity.
They also demonstrated how to use Cubeflow Pipelines, which enable the automation of entire MLOps life cycles, including data preparation, model training, and deployment.
Additionally, they introduced Data Preparation Kit (DPK), an open-source project designed to provide a consistent way to implement data processing tasks, making it easier for developers to create new models without requiring deep knowledge of infrastructure like Ray or Spark.
