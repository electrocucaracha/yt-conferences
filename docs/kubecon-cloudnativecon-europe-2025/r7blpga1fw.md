# Summary

The Cloud Native Computing Foundation (CNCF) has grown significantly since its founding in 2014, with 28 projects, 257,000 contributors, and 756 members.
The CNCF landscape is vast, with over 200 projects, but filtering through the options can be overwhelming.
To help navigate this, the CNCF provides a "What's Happening" tool that allows users to filter by project type, maturity level, and other criteria.
By using this tool, users can find projects that meet their needs and contribute to them, with opportunities for collaboration and growth.
