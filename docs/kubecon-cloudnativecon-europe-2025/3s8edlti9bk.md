# Summary

The Cloud Native Computing Foundation (CNCF) is an umbrella organization that aims to make cloud-native computing ubiquitous, with 28 projects, 257,000 contributors, and 96,000 community members.
The CNCF has been around for about 10 years, starting with Google's Kubernetes project in 2014.
The foundation provides a way to organize and understand the vast number of projects, which can be overwhelming.
The CNCF landscape is a tool that allows users to browse and filter projects by status, contributors, and other metrics, providing valuable insights into each project's maturity and potential for contribution.
