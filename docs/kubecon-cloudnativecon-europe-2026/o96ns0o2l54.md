# Summary

Limousine, the maintainer of the Hami project from Dynamia AI, introduces Hami as a smart and stable GPU sharing middleware for Kubernetes designed to address the inefficiency of traditional exclusive GPU allocation, which often results in low GPU utilization.
Hami enables GPU partitioning, allowing multiple tasks or users to share GPUs more effectively, either through its standard version or the advanced Hami AI.
Key advantages of Hami include user-friendly GPU slice allocation via resource limits without the need for resource claims, and guaranteed hard resource isolation within containers using a custom CUDA hacking library.
Installation is straightforward, requiring only compatible Nvidia drivers and Kubernetes versions, and Hami is integrated with the Volcano scheduler for enhanced resource management.
The project has seen wide adoption, particularly in China, and further information is available on GitHub, the project website, or through their Slack community.
