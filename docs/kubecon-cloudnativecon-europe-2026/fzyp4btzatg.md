# Summary

Augustin, a maintainer of Perses, introduces the project as a CNCF sandbox observability visualization tool capable of displaying metrics, logs, traces, and profiling data, with plans to support additional data sources like Polar Signals and Open Search.
Perses offers an open dashboard solution with extensible specifications in TypeScript, Go, and KuLang, and soon Java, allowing customization through plugins and validation rules.
The tool provides React components for embedding visualizations, a CLI for dashboard validation in CI/CD pipelines, and an operator for deployment, supporting a dashboard-as-code workflow with SDKs in KuLang and Go.
Perses is actively developed by contributors from Amadeus, Red Hat, and ASAP, has received EU funding, and recently reached 2,000 GitHub stars.
The community is growing, and interested users can connect via the official site, LinkedIn, X, or Slack, and are encouraged to visit the Perses booth at KubeCon.
