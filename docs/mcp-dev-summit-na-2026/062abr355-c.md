# Summary

In this talk, Lhari Chowi, an open source TPM at AWS, discusses the rapid growth and current state of the MCP server ecosystem.
MCP has evolved from a niche protocol to a sprawling ecosystem with tens of thousands of servers, registries, and tools, but this expansion has led to fragmentation and a lack of reliable discovery mechanisms.
Most MCP servers are experimental or poorly maintained, with only about 1% being production-ready and sustainable.
Chowi emphasizes that this fragmentation is a normal part of open source ecosystem development, but highlights the need for better documentation, onboarding, testing, and security to ensure long-term sustainability.
The key takeaway is that building reliable, well-maintained MCP servers is more valuable than simply increasing their number, and the community now has a unique opportunity to set strong standards and practices as the ecosystem matures.
