# Summary

The Kubernetes SIG CLI is responsible for developing and maintaining the CLI tooling, libraries, frameworks, and other tools used by users to interact with the Kubernetes project.
The group consists of chairs and tech leads who oversee various sub-projects, including Cube Control and Customize.
Customize is a tool that allows users to layer resources together and customize them, with the latest version being 5.8.0.
QRC (Quick Resource Configuration) is a new feature that enables users to change default values without modifying the original defaults.
The group is seeking feedback from users on various aspects of their tools, including Customize's documentation, which is in a "wildly bad state." They are also looking for help with implementing a new command that will be server-side by default and improving the overall documentation of their tools.
