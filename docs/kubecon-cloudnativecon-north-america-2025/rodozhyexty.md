# Summary

The speaker, Yan Tong, introduces himself as the maintainer of the Cords project, a DNS server written in Go, and discusses its features and benefits.
He explains how Cords can be used for virtual schooling, performance optimization with multi-socket plug-in, and service discovery with poding.
The project is community-driven, with over 400 contributors, 13,000 GitHub stars, and 38 public adopters.
Yan also covers the importance of DNS in cloud computing, its sensitivity to outages, and how Cords can be used to sync up with different cloud vendors.
He invites audience members to contribute to the project by coding, adding a star on GitHub, or becoming a maintainer.
