# Summary

The presentation discusses optimizing scheduling for large-scale big data distributed jobs in Kubernetes.
The default scheduler has limitations, including resource contention and poor data locality, which can lead to sub-optimal performance.
To address these gaps, the community is developing new schedulers, such as Volcano, Kai, and Apache Unicorn.
These schedulers offer features like gang scheduling, quotas, and preeemption, which are essential for large-scale distributed jobs.
Apache Unicorn has been developed to provide a unified solution for batch and long-running workloads, with a focus on simplicity and ease of use.
The presentation concludes by highlighting the need for community-driven development and collaboration to address the complex interactions between schedulers and workloads.
