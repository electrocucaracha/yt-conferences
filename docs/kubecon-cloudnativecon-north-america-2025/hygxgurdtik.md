# Summary

Ben Consalo, an AI engineer at AMD, presented a cloud-native preventive healthcare system that uses an agentic framework to generate patient-specific criteria for outreach emails.
The system is built on top of a Kubernetes orchestration, VLM model serving, and Prometheus observability.
It utilizes open-source models like Llama 3 and Deepsek R1, which can be used or fine-tuned for specific use cases.
The system aims to free up clinical staff time, reduce costs, and avoid vendor lock-in, making it suitable for healthcare organizations with limited resources.
