# Summary

The Backstage maintainer track talk discussed the project's updates, maturity, and new features.
The project now has 3,500 adopters, over 250 open-source plugins, and 31,800 stores on GitHub.
A community plugins repository was created to improve issue quality and reduce duplication.
The project is maturing its framework to excel at building developer portals with isolated plugins that are easy to maintain.
Declarative integration allows for a more drop-in solution for installing plugins, reducing the need for code knowledge.
The new frontend system is being developed, with a focus on declarative integration and improved tooling.
A model context protocol (MCP) standard was introduced to connect AI applications to external systems, enabling seamless interaction between Backstage and AI tools like Cursor and Claude.
The MCP actions backend plug-in allows developers to consume these tools from within Backstage.
