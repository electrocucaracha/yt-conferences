# Summary

Yamamoto, a researcher at LT Corporation in Japan, presented a photo build high-performance IML processing pipeline within the ML life cycles.
The current issue faced by ICT infrastructures is the need for real-time air processing due to advances in sensing, networking, and AI technologies, which drives the demand for high performance and power efficiency.
Yamamoto proposed an execution model called the processing pipeline, where each task uses the most suitable accelerator, achieving high performance per power consumption.
The concept of processing pipeline is rooted in data-centric approach, allowing application-side users to focus on the processing they want to perform without worrying about how it's deployed inside ICT infrastructures.
