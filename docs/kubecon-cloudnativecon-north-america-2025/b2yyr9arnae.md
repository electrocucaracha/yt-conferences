# Summary

Argo Rollouts has introduced a new feature called Canary Steps, which allows users to create custom deployment strategies using a plugin system.
This mechanism enables users to extend the functionality of Argo Rollouts and integrate it with their infrastructure.
The Canary Step plugin provides a common interface for traffic managers and metrics providers, allowing users to customize their deployment workflows.
With this feature, users can now focus on the core code of Argo Rollouts and create custom plugins to meet their specific use cases, making it easier to adopt and maintain the project.
