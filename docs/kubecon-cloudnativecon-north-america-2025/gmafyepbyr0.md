# Summary

The speaker discusses how software delivery changes require more from organizations each year, particularly with the adoption of AI.
They highlight three patterns in platform engineering: the ticket cue, where slow request processing creates safety challenges; "Oprah," where infrastructure for everyone leads to autonomy but responsibility issues; and the template pattern, which is flawed because it exposes teams to new tools without proper training or support.
The speaker proposes a new playbook for platform engineering, focusing on starting with an API that provides self-service, building relevant platforms, and treating them as managed services.
They emphasize the need for organizations to adopt global principles and tactics to build effective platforms, which can be applied regardless of organization size or experience.
