# Summary

Andrada, a DevOps engineer at ING Hubs Romania, will share the story of how their organization transitioned from code to cluster over five years.
The Kings Road pipeline was created to automate the CI/CD process for applications using the ING internal SDK and service mesh.
It uses Azure DevOps templates, with features like configurable deployment strategies, continuous delivery, and automated testing.
The pipeline also includes in-house features such as automatic image patching, configuration-only updates, and custom Docker images.
With a strong risk culture, the organization enables checks and validations to ensure reliable environments, including monitoring with Prometheus and Helm rollbacks.
