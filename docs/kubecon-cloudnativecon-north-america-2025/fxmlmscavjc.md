# Summary

The video transcript discusses the challenges of deploying agentic AI pilots in production, particularly in terms of security, observability, and governance.
The platform engineering team recognizes the need to bridge the gap between AI teams and Kubernetes, with a focus on networking, where they must now consider the body of requests, which contains critical information for AI workloads.
To address this, Envy company developed Agent Gateway, a data plan built from scratch in Rust that provides a layer 7 solution, including support for Kubernetes gateway API, LLM consumption, and MCP connectivity.
Additionally, the K agent project extends Kubernetes to provide context-aware runtime capabilities, while an upcoming project called Agent Registry aims to create a context-aware registry for managing AI artifacts, tools, and models.
