# Summary

Ezra Syla and Michael Rivven from IBM and Red Hat, respectively, presented on running high-performance AI workloads in virtual machines using Kubert, a Kubernetes-based project that allows native virtual machine execution.
They discussed performance challenges, including the need to address PCI topology issues, and how Kubert's dynamic XML injection feature can mitigate these problems.
The presentation also touched on integrating VM management tools with Nvidia tools, such as GPU partitions, and how Kubert's device plugin API can be leveraged to solve this issue.
The main takeaway is that Kubert provides a stable solution for running AI workloads in virtual machines, with many concrete customer use cases already being implemented.
