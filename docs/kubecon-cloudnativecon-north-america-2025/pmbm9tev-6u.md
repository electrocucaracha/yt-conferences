# Summary

The Harbor project has made significant progress over the past year, with 420 contributors and 71 entities contributing to the project.
The community has provided valuable feedback, which has helped shape the direction of the project.
Harbor's features include project management, repository management, artifact labeling, and vulnerability scanning.
The project is also working on improving its build infrastructure and test infrastructure, including support for ARM builds.
The Harbor CLI is almost complete, with most features already implemented, but still missing a few key features such as vulnerability dashboard and garbage collection.
The community is encouraged to provide feedback and participate in the development process through mailing lists, Slack channels, and community meetings.
