# Summary

The SIG cloud provider deep dive discussed the future of Kubernetes cloud providers, focusing on cross-platform building blocks and abstraction.
The panelists, including Bridget Cromhout from Microsoft Azure, Joel Speed from Red Hat, Jesse Butler from Amazon EKS, Elmo Miko from Google, and others, shared their excitement about Crow, a project aiming to create universal testing for cloud providers.
They emphasized the importance of making Kubernetes more agnostic and user-friendly, particularly for new contributors.
The conversation highlighted the need for faster development and testing, with Crow potentially playing a key role in achieving this goal.
