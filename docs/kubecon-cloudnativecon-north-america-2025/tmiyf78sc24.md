# Summary

The talk discusses GitOps and the manifest dilemma, focusing on templating tools for Kubernetes clusters.
The speaker shares their experience with using Argo CD and Helm, highlighting the importance of local rendering and health checks in a GitHub setting.
They also discuss the challenges of using incluster rendering tools like Crow and Crossplane, which require more automation and custom code to ensure proper functioning.
The speaker concludes by recommending out-of-cluster rendering tools for simplicity and ease of use, but acknowledges that incluster rendering may be suitable for specific use cases where it provides additional benefits.
