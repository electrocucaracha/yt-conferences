# Summary

The End User Technical Advisory Board (TAB) aims to represent the end-user community in the Cloud Native Computing Foundation (CNCF).
The TAB was created two years ago to address the lack of a user-focused perspective in CNCF governance.
The board's goals include promoting reference architectures, establishing feedback loops between projects and users, and identifying gaps in the ecosystem.
To achieve these objectives, the TAB collaborates with the Technical Oversight Committee (TOC) and engages with end-users through surveys, tech radars, and public meetings.
By bridging the gap between project developers and end-users, the TAB seeks to improve project maturity levels and increase transparency, ultimately benefiting both users and projects.
