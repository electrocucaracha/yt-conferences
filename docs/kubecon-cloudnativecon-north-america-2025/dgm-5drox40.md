# Summary

The Cluster Profile API is a community-driven, CRD-based namespace for standardizing cluster descriptions across multiple cloud providers.
Initially started in 2020, it has gained support from GKE, Azure Fleet Manager, and OCM, with multicluster runtime controllers already integrated to work with the API.
The API allows for secure access to clusters through a plugin-based system, enabling users to write custom controllers without needing prior knowledge of the plugin ecosystem.
To further improve adoption, the community is seeking input on adding properties to the cluster profile API and improving documentation, with plans for a plug-in registry and integrations with existing tools.
