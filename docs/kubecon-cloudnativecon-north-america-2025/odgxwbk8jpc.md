# Summary

A security expert, Stacey Butter, explains how a malicious payload was injected into her app's container image through a compromised compiler image.
She attributes the issue to a lack of vulnerability scanning and inadequate security measures in her project.
The Open Source Security Framework (OpenSSF) is introduced as a solution, providing a baseline for securing open-source projects with eight control families covering sustainability, documentation, governance, and more.
The framework has three levels, allowing developers to start at the foundation level and progress as their project matures.
Stacey invites viewers to join the OpenSSF community, contribute to its development, and participate in initiatives like Merge Forward and security showdowns.
