# Summary

The SIG Apps team from Kubernetes discussed best practices for managing data at scale and introduced new features in the upcoming release.
The team focuses on application user experience, including tools like Helm and CCompose, and sponsors working groups such as Batch and Serving.
New features include a "max unavailable" feature to improve update speed and flexibility, job access completion policy, pod replacement policy, and gang scheduling for workload management.
The team also discussed the need for improved stateful set handling and introduced the concept of agent sandbox for isolated stateful workloads.
